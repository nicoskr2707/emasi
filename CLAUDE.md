# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

Two things live here:

1. **The EMASI Propiedades website** (repo root): a static site (plain HTML/CSS/JS, no framework, no build step, no package manager, no tests, no linter) that recreates emasi.com.ar and adds a property catalog fed from a CSV.
2. **`EMASI/`**: brand and marketing knowledge for the client (briefs `00`–`09`, the EMASI Design System, logos, fonts, the identity manual PDF). These are reference material, not site code.

`_respaldo-sitio-anterior/` is a backup of the previous site version (old DM Sans/Krona One branding). Don't edit it or treat it as current. `emasi-sitio-para-subir.zip` is a packaged copy of the site for upload and goes stale when the root files change.

All content, comments, identifiers and copy are in **Rioplatense Spanish (voseo)**. Keep that convention.

## Commands

Serve locally. The catalog `fetch`es the CSV, so `file://` doesn't work:

```bash
python3 -m http.server 8000      # or: ruby -run -e httpd . -p 8000
# open http://localhost:8000/
```

Refresh catalog data from Tokko Broker (read-only GETs, stdlib only, Python 3.8+):

```bash
export TOKKO_API_KEY="..."
python3 tokko_propiedades_csv.py                     # writes propiedades.csv
python3 tokko_propiedades_csv.py -o salida.csv
python3 tokko_propiedades_csv.py --incluir-inactivas
```

## Architecture

**Data flow:** `tokko_propiedades_csv.py` → `propiedades.csv` (columns defined by `COLUMNAS` in the script) → fetched at runtime by `assets/js/data.js`. No property data is hardcoded in HTML. Only rows with `estado_listado = activa` are shown. If you rename or add a CSV column, update both `COLUMNAS`/`a_fila()` in the Python script and `normalizeProperty()` in `data.js`.

**JS is classic `<script>` tags sharing globals, not modules.** Load order matters and is the same on both catalog pages:
`csv-parse.js` (`parseCSV`) → `data.js` (`cargarPropiedades`, `normalizeProperty`, formatters, filter helpers) → `cards.js` (`renderCards`, `propertyCardHTML`, photo fallback placeholder) → `map.js` (Leaflet + OSM, `renderMapaGeneral` / `renderMapaPropiedad`) → the page entry point: `main.js` for `propiedades.html` (filters, reads `?q=&operacion=` from the home search bar) or `property.js` for `propiedad.html?id=…`. Leaflet 1.9.4 comes from unpkg with SRI.

**Shared chrome is duplicated, not templated.** Header, nav, footer and the small inline script (footer year + `nav-toggle` mobile menu) are copied into every page (`index`, `nosotros`, `tasaciones`, `formulario`, `contacto`, `propiedades`, `propiedad`, `404`). A nav or footer change has to be applied to all of them.

**No backend.** Forms (`formulario.html`, `contacto.html`) and the home search build a message and open WhatsApp or `mailto:` prefilled, or redirect with query params. Don't add server-side submission without discussing hosting first. Hosting is still undecided; the live emasi.com.ar runs on Hostinger Website Builder, which isn't connected to this repo. `robots.txt` and `sitemap.xml` point to emasi.com.ar.

**Styling:** everything is in `assets/css/styles.css`, which applies the EMASI Design System. Class names are coupled to the markup generated by `cards.js`/`main.js`/`property.js`, so renaming a class means updating the JS too.

## Brand rules (apply to any visual or copy change)

The source of truth is `EMASI/design-system/` (`README.md`, `colors_and_type.css`) plus `EMASI/recursos/01 MANUAL DE IDENTIDAD_EMASI.pdf`. Don't invent a new look.

- Palette: verde `#004742`, navy `#102D3E`, midnight `#3C3D4F`, celeste `#91B3CF` (the only accent), gris `#CCCCCC`, blanco. The only allowed gradient is a soft verde → navy. Max 3 colors per piece.
- Type: TT Neoris (400/500/700/800/900) and Golos Text, self-hosted as woff2 in `assets/fonts/`.
- Logos: use only the official stacked versions (white, green, navy, celeste, black). The isotipo can be used large, tone on tone, as a watermark.
- Tone (`EMASI/03_Tono_y_copy.md`): direct, professional, human. Avoid empty superlatives ("los mejores", "atención personalizada") and salesy exclamation marks.
- Never invent property data (prices, m², barrios, amenities). If a barrio is unclear, ask. EMASI operates only in CABA.
- Tasaciones are currently **free**. This has changed before, so confirm before writing tasación copy.
